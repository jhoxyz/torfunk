Torfunk

Formation

Ziehe die Kreise, um Positionen zu verschieben. Doppelklick auf eine Position benennt sie um.

Kader

    Ziehe Spieler auf eine Position oder tippe erst den Spieler, dann die Position an. Auf einer besetzten Position wird ausgewechselt. Zurück in die Liste ziehen nimmt einen Spieler vom Platz. Doppelklick auf einen Namen benennt um. Mit dem runden Knopf markierst du Spieler als verletzt, gesperrt oder nicht verfügbar.

    Du siehst eine geteilte Aufstellung. Dein eigener Kader und deine Aufstellung bleiben unverändert.
